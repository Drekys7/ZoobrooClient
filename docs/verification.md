# Проверка версии от 23.09.2026

## PWA — 24.09.2026

- Прежние 88 тестов прошли, новые 2 теста проверяют состав офлайн-ресурсов и размеры/непрозрачность иконок. Production-сборка и TypeScript проходят.
- Проверены HTTP-ответы манифеста, всех launcher-иконок и `sw.js`, ссылка на манифест в собранном HTML, `standalone`, относительные start URL/scope.
- Реальная браузерная проверка: production на отдельном `127.0.0.1:4175`, первое открытие, остановка только этого тестового сервера, перезагрузка вкладки. Карта общего вида отображается; поиск Clownfish и его краткие факты работают при выключенном сервере. Основной LAN-сервер 4174 не останавливался.
- Фото и подробные тайлы не скачиваются при установке заранее. Офлайн доступны ранее просмотренные ресурсы в пределах кеша; сохранность браузерного кеша не гарантируется.
- Установка на физических Android/iPhone и внешний HTTPS-хостинг ещё не проверены. Локальный HTTP IP-адрес телефона не является secure context.

## Предыдущие проверки

- `npm test`: 58 тестов успешно. Проверяются все ссылки на медиа и тайлы, SHA-256, версия схемы, перенос галерей/групп/стилей, фильтры и поиск, фотогалерея, расписания; повторная загрузка, rollback, отказ ресурса новой версии, отмена запроса и недоступное локальное хранилище.
- `npm run build`: строгая проверка TypeScript приложения и тестов, production-сборка Vite успешно.
- Production-сборка открыта в браузере по `http://127.0.0.1:4174/`.
- Размеры окна: 320×568, 390×844, 1440×900. Проверены общий вид, клик зоны с приближением, маркеры, карточка льва с фото/фактами/источником фотографии, поиск участника группы, возврат в группу, скрытие категории, немецкий/английский, пустое расписание, Escape и восстановление фокуса, изменение размера окна.
- В DOM проверена загрузка обзорного JPG 1254×1254, тайлов 512×512 и иконок 128×128; изображение 5016×5016 в обычном интерфейсе не создаётся. В консоли production не обнаружены ошибки.

Физические Android/iPhone, Safari, реальные сенсорные жесты и длительные измерения FPS ещё не проверялись. Размер окна браузера не заменяет тест на устройстве. Полный офлайн не заявлен.

Для следующей проверки производительности: использовать production (`npm run build`, `npm run preview -- --host 0.0.0.0`), медленный Android и iPhone, выполнить перемещение/щипок/открытие карточки при холодном и тёплом кеше; записать frame time, dropped frames, память и размер переданных данных в инструментах браузера. Проверять 60 FPS как бюджет 16,7 мс/кадр, отдельно устройства 90/120 Гц.

Дополнительно: переключение зон проверено до zoomend при непрерывном pinch/flyTo и CSS-зуме в обе стороны; одинаковая видимость не вызывает повторных обновлений React. В браузере проверены шрифт поиска 12 px и закрытие большого окна нажатием на 12 px левее видимой кнопки (область 55×55 px, визуальная кнопка 27×27 px).
